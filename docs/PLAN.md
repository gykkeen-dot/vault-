# План проекта

Ниша: высокая мода, архив, винтаж. Монетизация: подписка $7–15/мес + платные проверки экспертом $5–20 (магазины забирают 15–30%).

## Этапы (после каждого стоп и «ок»)
- **0. Основа**: каркас, 4 вкладки, бренды, лимиты, Supabase. (сделано)
- **1. MVP** (нед. 2–4): фото вещи → ИИ определяет бренд/коллекцию/сезон; аутфиты по правилам автора (нужно 30–50 луков с пояснениями).
- **2. Деньги** (нед. 5–6): Free/Premium, RevenueCat, экраны «лимит исчерпан».
- **3. Легитчек, бета** (нед. 7–10): Rick Owens, Balenciaga, Gucci; процент + разбор; платная проверка экспертом (нужны фото оригиналов и реплик).
- **4. Рост**: алерты, оценка цены, история продаж, гардероб, замеры по размерным сеткам.

## Легитчек: правила базы
- Берём факты и признаки из гайдов, чужие тексты и фото не копируем.
- Reddit для коммерческой базы не используем (нужен договор).
- Главная ценность: собственные размеченные фото. Базу регулярно обновлять.
- Везде: вероятностная оценка, не гарантия.
